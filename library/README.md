# Local master library

The PC manager creates `catalog.json` and `tracks/` here on first use. They are
personal data, ignored by Git and excluded from the source archive. Back them up
before changing computers. Original imports may live in the ignored `music/`
inbox or any other folder. Do not rename managed hash-named tracks manually.

Run `./scripts/music-manager.sh` from the project root to import music, manage
playlists and sync the mounted KERNIX_MUSIC partition.
